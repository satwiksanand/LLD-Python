### Types of Interview Types
There are 5 different types of LLD Interviews.

1. Object-Oriented Design(OOD): These kind of Interview revolve mainly around class Diagrams and Design Discussions.
2. Machine Coding Round: These Kind of Interview are mainly about coding a running solution within a time limited environment.
3. Concurrency Round: These kind of Interviews are mainly about Thread safety, Synchronization and Race Conditions.
4. API Design: These kind of Interviews are mainly about Interfaces, REST API designs and contracts.
5. Schema Design: These kind of Interviews are mainly about Database Tables design and designing the relationships between them.
